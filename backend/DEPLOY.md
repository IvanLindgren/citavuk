# Настройка Python upstream

Исправление сербской озвучки: загрузи актуальный `tts_service.py`.
Edge предоставляет голоса `sr-RS`; сербская латиница преобразуется в кириллицу
только перед синтезом, исходный текст не меняется. Версия ключа кеша v4
исключает старые записи v3, в том числе после fallback из ElevenLabs.
Новых секретов не требуется. Проверка: `python -m unittest backend.test_tts_service`.

При обновлении разбора загружай вместе с `main.py` новый runtime-модуль
`nlp_selection.py`. Он включён в `backend/Dockerfile`; обновление только одного
`main.py` без этого модуля приведёт к ошибке импорта. Проверка без моделей:
`python -m unittest discover -s backend -p 'test_nlp_selection.py'`.

Для аудио в образ также должны попасть `audio_transcription.py` и свежий
`main.py`: без первого Space запустится, но защищённая ручка распознавания
вернёт ошибку импорта.

Образ ставит `ffmpeg`. Он нужен не для обычных коротких записей, а для
безопасной перекодировки и разбивки больших M4A/WAV/OGG перед отправкой в STT:
Groq ограничивает multipart-файл 25 МБ на free-tier, поэтому длинный файл нельзя
просто передать одним запросом. MP3 режется по кадрам без перекодирования, а
остальные контейнеры — в моно OGG-фрагменты с сохранением смещения таймкодов.

Python-сервис принимает исходный IP только из заголовка Go API, защищённого
общим секретом. В Hugging Face Space открой **Settings → Variables and secrets**
и задай `CITAVUK_UPSTREAM_SECRET` тем же значением, что находится в корневом
`.env` и передаётся на VPS скриптом `server/deploy/sync-runtime-env.sh`.

Не записывай это значение в репозиторий, Dockerfile или клиентское приложение.
Без него сервис продолжит отвечать, но rate limit будет считать адрес прокси.

Для локальной аудиотеки добавь в те же секреты Space:

- `GROQ_AUDIO_TRANSCRIPTION_KEY` — ключ Groq (основная модель
  `whisper-large-v3-turbo`);
- `POLZA_AUDIO_TRANSCRIPTION_KEY` — ключ Polza.ai для резервной Aiesa-модели
  `aiesa/transcribe`.

Допустимы общие имена `GROQ_API_KEY` и `POLZA_AI_KEY`, но отдельные ключи
лучше: ими проще управлять и ограничивать квоту. Не добавляй ключи в Flutter,
React или multipart-запрос клиента — Go передаёт файл Python только через
внутренний защищённый proxy.
