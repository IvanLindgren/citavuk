# 🐺 Читавук

**Читавук** (рус. *читать* + серб. *вук* — волк) — приложение для изучения
сербского языка через чтение. Нажимаете слово в книге — получаете перевод
именно в этом предложении, разбор формы, объяснение по-русски и карточку для
повторения.

Работает на Android, Windows, Linux и в браузере: [citavuk.ru](https://citavuk.ru).

## Что умеет

- **Чтение с разбором.** PDF, DOCX, FB2, EPUB, DjVu, TXT и HTML. Перевод и
  морфологический разбор по нажатию, парадигмы склонения и спряжения.
- **Карточки.** Интервальное повторение (SM-2), общее расписание между
  устройствами и сайтом.
- **Курс грамматики** и тренажёр с упражнениями.
- **Аудирование** — подкасты с синхронной расшифровкой.
- **Материалы для поступления** в сербские гимназии и на факультеты.
  У каждого документа каталога есть кнопка «Составить тест по этому
  материалу»: вопросы, верный ответ и объяснение, почему он верный. Составленный
  тест общий — по одному документу модель вызывается один раз, остальным он
  открывается сразу. Раздел работает только на сайте.
- **Офлайн.** Чтение, грамматика и карточки работают без сети; словарь на
  9 тысяч слов скачивается один раз.

## Структура репозитория

| Каталог | Что внутри | Язык |
|---|---|---|
| `frontend/` | приложение: Android, Windows, Linux, веб-сборка | Dart, Flutter |
| `web/` | сайт citavuk.ru — читалка, курс, карточки | TypeScript, React, Vite |
| `server/` | сервер: аккаунты, синхронизация, перевод, грамматика | Go |
| `backend/` | прежний сервис разбора и аудио на Hugging Face | Python, FastAPI |
| `tools/` | утилиты: сборка словаря, курса, спрайтов, звуков | Python, Go |
| `course_content/` | тексты курса: юниты, уроки, упражнения | JSON, Markdown |
| `data/` | исходники для словаря (трибанк UD_Serbian-SET) | — |
| `docs/` | документы проекта, политика конфиденциальности | Markdown |

## Сборка форка

Ключи, пароли и адреса серверов в репозиторий не попадают: всё берётся из
переменных окружения, шаблон — `.env.example`. Форк собирается самостоятельно,
без доступа к чужой инфраструктуре.

### Приложение

```bash
cd frontend
flutter pub get
flutter run                      # отладка
flutter build apk --release      # Android
flutter build windows --release  # Windows
./deploy/linux/build.sh          # Linux, нужен Docker
flutter test                     # тесты
```

Подпись Android: положите свой keystore и `android/key.properties` — оба пути
в `.gitignore`. Без них сборка идёт с отладочным ключом.

### Сайт

```bash
cd web
npm install
npm run dev        # локальный сервер
npm run build      # сборка в dist/
npx vitest run     # тесты
```

По умолчанию сайт обращается к `https://api.citavuk.ru`; свой адрес задаётся в
`src/api/client.ts`.

### Сервер

```bash
cd server
go test ./...
go build ./cmd/citavukd
```

Нужен PostgreSQL; переменные окружения перечислены в `internal/config`.
Миграции применяются при старте. Выкладка — `deploy/deploy.sh`, адрес сервера и
ssh-ключ задаются через `CITAVUK_HOST` и `CITAVUK_SSH_KEY`.

### Словарь и ресурсы

```bash
python tools/lexicon_export.py      # словарь для сервера из assets/lexicon.db
python tools/make_page_turn.py      # звук перелистывания страницы
```

портирован из [djvu-rs](https://github.com/matyushkin/djvu-rs) (MIT),
написанного по открытой спецификации DjVu v3; словарь собран из трибанка
[UD_Serbian-SET](https://github.com/UniversalDependencies/UD_Serbian-SET).

Книги в репозиторий не входят — приложение открывает файлы пользователя.
