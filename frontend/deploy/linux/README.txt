Читавук для Linux (x86-64)
==========================

Сербский через чтение: открываете книгу или документ, нажимаете любое слово и
видите перевод в этом предложении, разбор формы и объяснение по-русски.

Установка
---------

    tar -xzf citavuk-linux-x64.tar.gz
    cd citavuk-*-linux-x64
    ./install.sh

Приложение уходит в ~/.local/share/citavuk, ярлык появляется в меню, а команда
citavuk — в ~/.local/bin. Права root не нужны.

Удалить:

    ./install.sh --uninstall

Можно и не устанавливать — запустить прямо из распакованного каталога:

    ./srbski_read

Требования
----------

Сборка сделана на Ubuntu 22.04, то есть на glibc 2.35: работает на ней и на всём
более свежем. Из библиотек нужны GTK 3, GStreamer (звук в разделе слушания) и
webkit2gtk 4.1 (вход через Google и Яндекс открывается во встроенном окне). На
обычном рабочем столе с GNOME или KDE всё это уже стоит; если чего-то не
хватает, приложение скажет об этом при запуске.

Debian, Ubuntu и производные:

    sudo apt install libgtk-3-0 libgstreamer1.0-0 \
        gstreamer1.0-plugins-good libwebkit2gtk-4.1-0

Fedora:

    sudo dnf install gtk3 gstreamer1-plugins-good webkit2gtk4.1

Данные
------

Книги, словарь и карточки хранятся в ~/.local/share/citavuk-data. Войдите в
аккаунт, чтобы они были такими же на телефоне, в браузере и на других
компьютерах.

Исходники и сайт: https://citavuk.ru
