# Промпт для ИИ-агента: контент Читавука

Скопируй этот файл целиком в задачу агенту. Он описывает форматы, возможности
редактора и способ проверки — без него агент сочинит правдоподобный JSON,
который сервер отвергнет или, хуже, примет, а урок окажется нерабочим.

---

Ты готовишь учебный материал для сайта citavuk.ru — сербский язык для
русскоязычных. Материал уходит живым людям, поэтому выдумывать слова, формы и
переводы нельзя: сомневаешься в форме — не используй её.

## Что и куда можно заливать

| Что | Куда | Когда увидят люди |
| --- | --- | --- |
| Урок: теория + упражнения + диалог | API, `upload_lesson.py` | сразу после публикации |
| Диалог | внутрь урока, поле `content.dialogue` | сразу после публикации |
| Упражнения курса и Тренажёрки | репозиторий, `add_course_exercises.py` | после выкатки сайта и приложения |

Тренажёрка своих упражнений не хранит: она берёт их из курса по `skillId`.
Поэтому «упражнение в тренажёрку» — это упражнение в уроке нужного навыка в
`course_content/units/*.json`, и попадёт оно к людям только со следующей
выкаткой. Если материал нужен сегодня — делай урок, а не правку курса.

**Форматы упражнений у этих двух каналов разные, и перепутать их легко.**
В уроке варианты ответа — просто строки, а верный назван отдельно:

```json
{"type": "multiple_choice", "options": ["radim", "radiš"], "answer": "radim"}
```

В курсе вариант — объект, и верный помечен внутри:

```json
{"type": "multiple_choice", "options": [{"id": "a", "text": "radim", "correct": true},
                                        {"id": "b", "text": "radiš"}]}
```

Дальше в этом файле описан формат **урока**. Формат курса — в
`course_content/SCHEMA.md`; там же таблица полей, которые дописывает
нормализатор (`id`, `difficulty`, `sourceRef` и прочее руками писать не нужно).

## Урок: файл целиком

```json
{
  "slug": "lokativ-gde-ja",
  "title": "Локатив: где я нахожусь",
  "summary": "Одно-два предложения для карточки в каталоге.",
  "level": "A2",
  "lessonType": "grammar",
  "topic": "Локатив",
  "tags": ["падежи", "локатив"],
  "estimatedMinutes": 15,
  "script": "latin",
  "content": { "theory": [], "exercises": [], "dialogue": {} }
}
```

- `slug` сервером не принимается, его использует скрипт: повторный запуск с тем
  же `slug` обновляет урок, а не плодит второй с тем же названием.
- `level` — `A1 A2 B1 B2 C1 C2`. `lessonType` — `lexicon grammar speaking writing`.
- `script` — `latin cyrillic both`. Смешивать графики внутри одного урока не надо.
- `estimatedMinutes` — 1…240, честно: 12 упражнений за 5 минут не проходят.
- `tags` — до 12 штук, до 40 знаков каждый.
- Картинки и обложки — только по `https`.

## Теория: до 6000 видимых знаков

Список блоков. Знаки считаются по всем текстам, ссылки не в счёт.

| Блок | Поля |
| --- | --- |
| `paragraph` | `text` |
| `heading` | `text` |
| `quote` | `text` |
| `list` | `items` (строки), `ordered` |
| `table` | `rows` — список строк, первая считается шапкой |
| `image` | `url` (https), `alt`, `caption` |
| `video` | `url` — только YouTube, VK Video, Rutube, Vimeo |

У каждого блока полезно указывать `id` — по нему редактор различает блоки.

### Чем пользоваться, чтобы урок не был полотном

`content.theory` обязателен всегда — по нему урок показывает приложение.
Дополнительно можно положить `content.markdown`: на сайте он **перекрывает**
`theory`, поэтому либо не пиши его вовсе, либо пиши тем же содержанием. Пустой
`markdown` при непустой теории означает пустой урок на сайте — сервер такое
пропустит, а читатель увидит «Материал пока пуст».

Markdown понимает GFM плюс три своих расширения:

- `## Заголовок`, списки `- `, `1. `, цитаты `> `, таблицы GFM;
- `**жирный**`, `*курсив*`, `` `код` ``;
- `@[video](https://youtu.be/...)` — видео;
- `{size=24}крупная строка{/size}` — кегль;
- `{font=sans}рубленый шрифт{/font}` — гарнитура.

Что делает урок читаемым на деле:

- **Заголовок каждые два-три абзаца.** Длина строки ограничена 62 знаками, и
  сплошной текст на телефоне превращается в стену.
- **Таблица вместо перечисления форм.** «kuća → kući, sto → stolu» списком
  читается вдвое хуже, чем те же три строки таблицей.
- **Цитата — для правила, которое стоит запомнить.** Одна на урок, не пять.
- **Абзац — одна мысль.** Пятистрочный абзац пролистывают.
- Сербские слова пиши как есть: в тексте урока они кликабельны, читатель сам
  разберёт слово и заберёт в словарь. Дублировать перевод в скобках не нужно.

## Упражнения

Главное правило: **у каждого типа есть условие, при котором он оживает**. Не
выполнил условие — задание не сломается, а молча станет полем свободного
ответа. Урок будет выглядеть целым, а проверять ничего не будет. Валидатор
ловит именно это.

| Тип | Что обязательно | Что ещё бывает |
| --- | --- | --- |
| `multiple_choice` | `options` (строки), `answer` из этого списка | `multi` не поддерживается |
| `ending_picker` | `options` и `context` (или `stem`) | |
| `sentence_builder` | `tokens` — слова вразбивку | `distractors` |
| `letter_unscramble` | `answer` — слово целиком | |
| `matching` | `pairs`: `[{"left": "...", "right": "..."}]` | |
| `fill_blank` | `context` с пропуском `___`, `answer` | `acceptedAnswers` |
| `image_description` | `prompt`, `imageUrl` (https) | `criteria`, `referenceAnswer` |
| `reading_qa` | `readingText` и `questions` | вопрос: `prompt`, `options`, `answer` |
| `form_hunt` | `context` и `targetWords` | |
| `word_drill` | `pairs` — перевод слева, слово справа | |
| `translator_duel` | `context` (фраза) и `answer` (эталон) | `referenceAnswer` — перевод машины |
| `explain_word` | `prompt` | свободный ответ |
| `teacher_letter` | `prompt` | письмо преподавателю |

У каждого упражнения: свой `id`, `prompt` и `explanation`. Объяснение
обязательно по смыслу: ошибка без разбора ничему не учит.

**Пунктуация в ответах не проверяется** — точки, запятые и кавычки снимаются
перед сравнением. А вот `č/ć` и `dž/đ` различаются строго: на них половина
упражнений и держится.

## Диалог

```json
"dialogue": {
  "startId": "d1",
  "nodes": [
    {"id": "d1", "speaker": "Ana", "avatar": "woman", "text": "Gde si?",
     "choices": [{"label": "U kući sam.", "nextId": "d2"}]},
    {"id": "d2", "speaker": "Ana", "avatar": "woman", "text": "Odlično!"}
  ]
}
```

- `avatar` — `teacher`, `student`, `woman`, `man`.
- Пустой `nextId` — законный конец ветки. Ссылка на несуществующую реплику —
  нет: сервер её обнулит, и разговор оборвётся посреди фразы.
- До каждой реплики должен быть путь от `startId`. Недостижимая ветка — работа,
  которую никто не увидит.
- Возврат к началу разрешён: цикл — обычный ход сценария.

## Как проверять и заливать

```bash
# только проверка, ничего не отправляется
python tools/content_upload/upload_lesson.py lesson.json --dry-run

# выложить по ссылке
python tools/content_upload/upload_lesson.py lesson.json --publish unlisted

# выложить в общий каталог от имени владельца
python tools/content_upload/upload_lesson.py lesson.json --publish public --approve

# упражнения курса и Тренажёрки (через репозиторий)
python tools/content_upload/add_course_exercises.py exercises.json --dry-run
```

`ОШИБКА` — сервер урок не примет, публикация не начнётся. `замечание` — примет,
но получится плохо; решай сам.

Пример полного урока: `tools/content_upload/examples/lesson.json`.

## Чего делать нельзя

- Придумывать сербские слова и формы. Не уверен — возьми другое слово.
- Копировать теорию из учебника дословно. Своими словами и коротко.
- Ставить `answer`, которого нет среди `options`: задание станет непроходимым.
- Писать в интерфейсе о внутренней кухне — движках, версиях, статусах сборки.
- Обращаться к читателю на «вы» с большой буквы. В Читавуке говорят на «ты».
