# Фразы «Ты против переводчика»

По одному предложению на строку. `sr-ru` — сербская латиница, `ru-sr` — русский.
Файлы встраиваются в сервер через `go:embed`, клиент своей копии не имеет.

Первые 15 строк каждого файла — старый банк; порядок нельзя менять:
строка задаёт стабильный идентификатор фразы. Новые задания дописываются.

28.09.2026: +1615 фраз, всего 1795. Источники:

- Имеющиеся примеры проекта `tools/data/roadmap_examples_{a1,a2,b1,b2,c1,c2}.tsv`.
  Удалены только маркеры выделения `*`. Для сербского банка взяты чётные строки
  (нумерация с нуля), для русского — нечётные: один пример не используется
  сразу в обоих направлениях.
- Отдельно подготовленные оригинальные черновики по 100 предложений:
  sr-ru/A2, ru-sr/A1, ru-sr/A2, ru-sr/B2. Модель
  `deepseek/deepseek-v4-flash-0731`, reasoning low. Однократная подготовка,
  не часть runtime. Проверены письмо, длина, уникальность и выборка формулировок.
  Полной проверки каждого предложения носителем языка не было.

Неудачные/незавершённые ответы провайдера не импортированы.
Черновики находятся в `output/translation-phrases-drafts/translation-phrases-20260928`;
в бинарник входят только текстовые файлы этого каталога.

Уровень у примеров дорожной карты определяется также лексикой: короткая
фраза C1/C2 может содержать редкое слово без длинной синтаксической конструкции.

Тесты проверяют минимум 1000 новых фраз в общем банке, отсутствие дублей,
прежние строки и работу перемешивания для старого клиента и общей комнаты.
Постоянная история увиденных заданий ещё не ведётся: между разными партиями
повтор возможен, внутри трёх раундов — нет.
