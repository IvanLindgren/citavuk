# Поддержка проекта через ЮKassa

Магазин оформлен на самозанятого. С 29.12.2025 ЮKassa не отправляет чеки
самозанятых в «Мой налог» сама: чек на каждое поступление пробивается вручную,
для безналичных оплат — до 9-го числа следующего месяца. Список за месяц есть в
админке, раздел «Поддержка».

## Подключение

1. yookassa.ru → «Подключиться» → «Самозанятый»: ИНН, вход через «Мой налог».
   Сайт — `https://citavuk.ru`. Описание: поддержка образовательного сервиса,
   поддержавший получает значок, место в списке и косметику.
2. Модерация смотрит `/support`: описание, цены, условия, возврат, контакты.
   ФИО и ИНН продавца заданы в `web/src/pages/supportSeller.ts`.
3. Сначала тестовый магазин: «Интеграция» → «Ключи API» → `shopId` и
   секретный ключ `test_…`. Тестовые карты — в разделе «Тестирование»
   документации ЮKassa.
4. «Интеграция» → «HTTP-уведомления»: URL
   `https://api.citavuk.ru/v1/donations/yookassa`, события
   `payment.succeeded`, `payment.canceled`, `refund.succeeded`. То же — в
   боевом магазине после модерации.
5. На VPS в `/opt/citavuk/.env`:

   ```
   YOOKASSA_SHOP_ID="…"
   YOOKASSA_SECRET_KEY="…"
   ```

   и `systemctl restart citavuk-api`. В репозиторий ключи не кладутся.

## Тестовый режим

Пока ключ магазина начинается с `test_`, создавать платежи может только
администратор: тестовые карты общеизвестны, и иначе бонусы доставались бы
даром. Исключение — почты из `YOOKASSA_TEST_PAYERS` (через запятую): так
проверяющий ЮKassa проходит оплату сам. Для модерации заведён аккаунт
`test@citavuk.ru` (почта подтверждена в базе в обход регистрации, пароль
передан в ЮKassa). Платёж с `test: true` помечается `donations.is_test`: он даёт значок
(чтобы проверить путь целиком), но не попадает в список друзей и в суммы для
чеков. Все платежи до миграции 0051 были тестовыми и помечены ею.

## Как устроено

- `POST /v1/donations` (гость или аккаунт) создаёт запись `donations` и платёж
  с `Idempotence-Key` = id записи и `metadata.donation_id`. Клиент уходит на
  `confirmation_url`, после оплаты возвращается на `/support/thanks?d=<id>`.
- Уведомление не подписано, поэтому сервер берёт из него только id и
  перезапрашивает платёж (`GET /v3/payments/{id}`) своим ключом. Ответ не 200
  заставляет ЮKassa повторить доставку в течение суток.
- `GET /v1/donations/{id}` отдаёт статус странице благодарности и сам
  перезапрашивает ЮKassa, если уведомление ещё не пришло.
- Сумма оплат аккаунта ≥ 200 ₽ выставляет `users.supporter_since`, возврат ниже
  порога снимает его. `/v1/auth/me` отдаёт `supporterSince`.
- `GET /v1/supporters` — публичный список: имя и дата, без сумм. Аккаунт
  показывается один раз под последним указанным именем.
- `GET /v1/admin/donations?month=2026-09` — платежи месяца для чеков,
  `POST /v1/admin/donations/manual` — внести поддержку, пришедшую мимо ЮKassa
  (старый сбор ЮMoney).
- Оплата только на сайте: Android-приложение ведёт на `/support` в браузере и
  само ничего не продаёт (правила Google Play о цифровых товарах).
