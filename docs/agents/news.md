# «Вести» и чек-лист дня (только сайт, 07.11.2026)

Два раздела сайта, которые живут вместе: газета `/vesti` и чек-лист `/dan`.
Чек-лист предлагает один из четырёх пунктов — «почитать» — именно в газете.
В приложении (Flutter) их пока нет.

## Газета: сервер (`server/internal/news/`)

- `sources.go` — полосы и их RSS. Полоса — код, сербское название и 1–3 ленты:
  N1, RTS, BBC na srpskom, B92, Danas, Nova, Startit, Sport Klub. Рядом два
  списка хостов: `articleHosts` (откуда можно открыть заметку) и `imageHosts`
  (откуда можно взять снимок). Новый источник = лента в `Sections` + хосты в
  оба списка + имя в карте `sources` (`article.go`), иначе заметка не откроется
  или останется без подписи.
- `news.go` — номер. `Issue(ctx, fresh)` держит номер час; `fresh` печатает
  заново, если номеру больше пяти минут (кнопка «Свежий номер» не бьёт по
  изданиям каждую секунду). Не напечаталось — отдаётся прежний номер. На
  полосе 7 заметок, передовица — свежая заметка со снимком. Снимок в ответе —
  не адрес, а id: браузер берёт его через `/v1/news/image/{id}`, так издание
  не видит читателя.
- `article.go` — заметка целиком. Облегчённая readability: каждый `<p>` длиннее
  40 знаков добавляет очки четырём предкам с затуханием (`длина/глубина`),
  побеждает узел с наибольшим счётом (не меньше 150). Блоки на выходе:
  `p`, `h`, `img`, `youtube`, `video`. Шумовые узлы (`related`, `share`,
  `comment`, `sidebar`…) отсекаются по точному совпадению части класса, а не
  по подстроке: у N1 `article-content` иначе выпадал целиком. Кеш 6 ч.
- `videos.go` — ролики. `Interests` — темы с проверенными channel_id
  (язык, путешествия, кухня, история, наука, разговоры, юмор, спорт,
  культура, авто, новости). Источник — RSS канала
  `youtube.com/feeds/videos.xml?channel_id=…`, кеш канала 3 ч. Shorts
  помечаются по ссылке `/shorts/` и идут последними.

Ручки — в `server/internal/api/news_handlers.go`, список — в
`server/README.md`. Прокси снимков проверяет хост и после редиректов, тип
`image/*` без SVG и размер.

Тесты: `go test ./internal/news/` — офлайн на образцах. Живой прогон по всем
лентам: `CITAVUK_NETWORK_TESTS=1 go test ./internal/news/ -run Live`.

## Газета: сайт (`web/src/pages/News.tsx`, `news.css`)

- Вёрстка как у бумажной газеты: двойная линейка, шапка «Вести / Читавука»
  шрифтом Prata, строка выпуска (номер = час года), полосы с двойной линейкой,
  передовица со снимком и буквицей, остальное — CSS-колонками 3/2/1 с
  линейками между ними. Снимки чуть обесцвечены и оживают при наведении.
- `NewsPress.tsx` — сцена «Читавук разворачивает газету» (2,7 с) при каждом
  новом номере: первый заход, «Свежий номер», ежечасное обновление открытой
  вкладки. При «уменьшить движение» её нет; клик пропускает.
- Тексты идут через `WordReader calm`: каждое слово нажимается. Класс
  `reader-selectable` обязателен — `paragraphClassName` заменяет классы
  абзаца целиком.
- `LiteYouTube.tsx` — ролик грузится только по нажатию (`youtube-nocookie`),
  до того на странице только обложка через наш сервер.
- Выбор полос — `localStorage` `citavuk-vesti-sections`.

## Чек-лист дня (`web/src/pages/Checklist.tsx`, `lib/checklist.ts`)

Включается по желанию на самой странице; состояние — в `localStorage`
(`citavuk-checklist:<хранилище>`), это привычка на устройстве, на сервер не
уходит. Отметки дня обнуляются сменой даты; `history` — дни, закрытые
целиком (полоска недели и серия).

| Пункт | Что предлагается | Отмечается сам |
|---|---|---|
| `lesson` | следующий непройденный открытый урок курса | `saveLessonProgress` при сдаче урока; урок с `completedAt` сегодня |
| `words` | слова дня (`DailyPanel`), гостю — вход | все слова набора выучены |
| `video` | ролик дня по интересам, «Другое видео» | минута просмотра (`LiteYouTube onWatched`) |
| `read` | заметка из «Вестей» или свой текст из слов дня | открыта заметка; текст дня составлен |

Ролик дня запоминается в состоянии (`video`): подборка обновляется в течение
дня, и без этого ролик менялся бы при каждом заходе. Любой пункт можно
отметить и снять вручную. С включённым чек-листом автоматическое окно слов
дня не всплывает (`DailyWindow`).

В шапке: «Новости» — в группе «Читать», «Чек-лист дня» — в «Учиться». Оба
адреса есть в `location @app` nginx; баннеры и окна на них не показываются
(`quiet` в `App.tsx`).
