# Политика конфиденциальности «Читавук»

Дата вступления в силу: 4 октября 2026 года.

«Читавук» (далее — приложение) — программа для чтения книг на сербском языке с
разбором слов, карточками и курсом. Приложение доступно на iPhone и iPad,
Android, macOS, Windows, Linux и на сайте citavuk.ru.

Оператор данных: Денис Корнилов. Связь: deniskornilov12@gmail.com.

## Коротко

- Без аккаунта приложение хранит книги, слова и прогресс только на устройстве.
- Аккаунт нужен, чтобы те же данные были на телефоне, компьютере и сайте.
- Рекламы, трекеров и систем аналитики в приложении нет.
- Данные не продаются и не передаются третьим лицам для маркетинга.
- Аккаунт можно удалить вместе со всеми данными в любой момент.

## Какие данные обрабатываются

### Без регистрации

Библиотека, добавленные слова, карточки, прогресс чтения и курса хранятся
локально на устройстве и на сервер не отправляются.

На сервер уходит только текст, который нужно перевести или разобрать: отдельное
слово или предложение, в котором оно встретилось. Такой запрос анонимен — он не
связывается с человеком и не сохраняется в профиле. Переводы кэшируются на
сервере по содержимому текста, чтобы не запрашивать одно и то же повторно.

### С аккаунтом

При регистрации сохраняются:

- адрес электронной почты и отображаемое имя;
- хеш пароля (сам пароль не хранится) — если вход по паролю;
- идентификатор аккаунта провайдера, если вход через Google, Яндекс ID или Apple;
- при входе через Apple — ключ доступа, выданный Apple: по нему при удалении
  аккаунта отзывается доступ приложения к Apple ID;
- активные сессии: хеш токена, название и платформа устройства, время входа.

При включённой синхронизации сохраняются данные обучения:

- список книг и их текст (нужен, чтобы открыть книгу на другом устройстве);
- сохранённые слова, переводы, грамматические разборы;
- карточки повторения и расписание повторов;
- прогресс курса и «дворцы памяти».

### Обсуждения

Сообщения в обсуждениях (страницы общей книги, карточки Вукотока, уровни карты
пути) видны всем вместе с отображаемым именем автора. Сообщения с грубыми
словами не принимаются. На чужое сообщение можно пожаловаться: текст сообщения,
имя автора, причина и почта пожаловавшегося уходят модератору в Telegram и там
не хранятся дольше, чем нужно для решения. Скрытые авторы запоминаются только на
устройстве. Правила обсуждений показываются перед первым сообщением: оскорбления,
мат, угрозы, разжигание ненависти, спам и непристойности запрещены, нарушения
удаляются, аккаунты нарушителей блокируются.

### Голос в «Говори!»

Записанный голос отправляется на распознавание речи, а получившийся текст — на
разбор ошибок языковой моделью. Сервер Читавука не хранит ни запись, ни текст:
файл передаётся распознаванию и сразу отбрасывается, а в аккаунте остаётся
только отметка о занятии для календаря учёбы.

### Что не собирается

Приложение не собирает геолокацию, контакты, список установленных программ,
идентификаторы рекламы, историю просмотров вне приложения. Аналитики поведения
и краш-репортинга нет.

## Зачем данные обрабатываются

- Вход в аккаунт и защита от несанкционированного доступа.
- Синхронизация библиотеки и прогресса между устройствами.
- Перевод и грамматический разбор слов.
- Подтверждение адреса электронной почты и восстановление доступа.

Правовое основание — исполнение договора с пользователем (предоставление
функций приложения) и согласие, которое даётся при создании аккаунта.

## Поддержка проекта

При поддержке проекта сохраняются сумма, статус и идентификатор оплаты,
выбранные имя и сообщение, разрешения на их публикацию и, после привязки,
аккаунт. Банковские данные вводятся на стороне ЮKassa и не поступают Читавуку.
Для привязки гостевой поддержки к аккаунту используется защищённая cookie
на 90 дней. Необязательная почта для ссылки на другом устройстве нужна
только для этого письма, не для рекламы; она удаляется после привязки
или истечения 90 дней. На сервере хранятся только хеши подтверждений,
ссылка из письма действует 3 дня и используется один раз.

## Кому передаются данные

Только тем сервисам, без которых функция не работает:

| Получатель | Что передаётся | Зачем |
|---|---|---|
| DeepL SE (Германия) | текст для перевода | машинный перевод слов и фраз |
| Google LLC | текст для перевода | запасной переводчик, когда DeepL недоступен |
| Google LLC | данные входа Google | вход через аккаунт Google |
| Яндекс | данные входа Яндекс ID | вход через Яндекс ID |
| Apple Inc. | данные входа Apple ID | вход через Apple |
| Groq, Inc. (США) | запись голоса | распознавание речи в «Говори!» |
| Polza.ai | запись голоса, распознанный текст | запасное распознавание и разбор ошибок в «Говори!» |
| Telegram | текст жалобы на сообщение | доставка жалобы модератору |
| ЮKassa | сумма и идентификатор оплаты | приём поддержки проекта |
| Resend | почта и служебное письмо | подтверждение аккаунта и привязка гостевой поддержки |

Тексты для перевода передаются без привязки к аккаунту. Полученные переводы
подчиняются политикам соответствующих сервисов.

Данные не передаются рекламным сетям, брокерам данных и не используются для
профилирования.

## Где и сколько хранятся данные

Данные хранятся на арендованном сервере в Европейском союзе (PostgreSQL,
шифрованное соединение). Данные аккаунта хранятся, пока аккаунт существует.
Сессии удаляются по истечении срока. Кэш переводов хранится не более
одного года и не привязан к человеку.

## Удаление аккаунта и данных

Аккаунт удаляется целиком, вместе с книгами, словами, карточками и прогрессом:

- в приложении: «Ещё» → «Аккаунт и синхронизация» → «Удалить аккаунт»;
- на сайте: [citavuk.ru/account](https://citavuk.ru/account) → «Удалить аккаунт»;
- письмом на deniskornilov12@gmail.com с адреса, на который зарегистрирован
  аккаунт.

При входе через Apple вместе с аккаунтом отзывается и доступ приложения к
Apple ID. Удаление необратимо и выполняется сразу. Резервные копии базы данных
перезаписываются в течение 30 дней. Данные на самом устройстве при этом
остаются — их удаляет удаление приложения.

## Дети

Приложение не предназначено для детей младше 13 лет и не собирает данные о них
намеренно.

## Права пользователя

Можно запросить копию своих данных, исправление неточностей, удаление данных
или отзыв согласия — письмом на deniskornilov12@gmail.com. Ответ даётся в
течение 30 дней.

## Безопасность

Соединение с сервером идёт по HTTPS. Пароли хранятся в виде хеша, токены
сессий — в виде SHA-256. Доступ к серверу ограничен ключами.

## Изменения политики

При изменении политики дата вступления в силу обновляется, а актуальная версия
публикуется по адресу [citavuk.ru/privacy](https://citavuk.ru/privacy). О
существенных изменениях сообщается в приложении.
